# Student Management REST API

This project is a simple Student Management REST API developed using Node.js and Express.js.

## Features

- GET all students
- Add a new student
- Update student details
- Delete a student
- Custom middleware to display request methods

## Technologies Used

- Node.js
- Express.js
- Postman

## Project Structure

student-management-api/
│
├── controllers/
├── middleware/
├── models/
├── routes/
├── server.js

## Installation

1. Install dependencies

npm install

2. Run the server

node server.js

## Server

The server runs on:

http://localhost:3000

## API Endpoints

### GET
/students

### POST
/students

### PUT
/students/:id

### DELETE
/students/:id
